# 코드 스타일 (공통)

프로젝트 언어/프레임워크별 스타일은 프리셋(`presets/`)이 추가하는 `<스택>-style.md`가 이 파일에 더해 적용된다.
프리셋이 없다면 아래를 따르고, 프로젝트가 정하면 이 문서를 갱신한다.

- 기존 코드의 스타일과 이름 규칙을 따른다.
- 린터/포매터가 있으면 그 설정을 따르고, 커밋 전에 통과시킨다.
- 주석은 "왜"를 설명한다. 자명한 "무엇"은 쓰지 않는다.
- 사용하지 않는 코드, 디버그 출력은 남기지 않는다.
- 외부 입력(파일, 네트워크, 사용자 입력)은 검증하고 신뢰하지 않는다.
- 커밋 메시지 접두어와 코드 식별자는 영문, 사용자에게 보이는 문구의 언어는 프로젝트 정책을 따른다.
